# One-Room Shooter

Player: A simple player character moved by keyboard input on one screen.
Objective: Survive for 60 seconds while shooting enemies.
Main obstacle: Enemies that spawn and move toward the player.
Win condition: The player survives until the timer ends.
Lose condition: The player's health reaches zero.

## Scope

Build the smallest complete Godot 4 2D project that teaches projectiles, cooldowns, enemy movement, health and damage, spawning, basic reusable components, and restarting.

Do not add extra weapons, enemy types, upgrades, pickups, scoring, levels, art polish, sound, menus beyond what the loop needs, settings, or shared framework code.
