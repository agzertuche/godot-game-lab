# Collect Everything

Player: A simple player character moved by keyboard input on one screen.
Objective: Collect ten objects before time runs out.
Main obstacle: The 30-second countdown timer.
Win condition: The player collects ten objects.
Lose condition: The timer reaches zero before ten objects are collected.

## Scope

Build the smallest complete Godot 4 2D project that teaches `Area2D`, signals, counters, random placement, removing collected objects, basic win/loss state management, and restarting.

Do not add enemies, levels, scoring beyond the counter, art polish, sound, menus beyond what the loop needs, settings, or shared framework code.
