# Tiny Tower Defense

Player: A defender who places towers with the mouse.
Objective: Survive three enemy waves.
Main obstacle: Enemies following one fixed path toward the base.
Win condition: All three waves are cleared.
Lose condition: Base health reaches zero.

## Scope

Build the smallest complete Godot 4 2D project that teaches `Path2D` and `PathFollow2D`, mouse input, placement validation, target selection, attack range, currency, wave sequencing, and restarting.

Do not add upgrades, branching paths, multiple tower types, multiple enemy types, selling, art polish, sound, menus beyond what the loop needs, settings, or shared framework code.
