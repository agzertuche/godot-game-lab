# Tiny Garden Idle

Player: A gardener tending a small one-screen garden.
Objective: Grow the garden until it earns 500 total coins.
Main obstacle: Choosing between buying new plots and improving watering.
Win condition: Total earned coins reaches 500.
Lose condition: None.

## Scope

Build the smallest complete Godot 4 2D project that teaches timers, passive income, button-driven interaction, incremental costs, UI state, simple visual feedback, win state, and restarting.

Do not add save data, offline progress, prestige, multiple currencies, multiple screens, inventories, art polish, sound, settings, or shared framework code.
