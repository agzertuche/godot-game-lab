# Tiny Kitchen Rush

Player: A cook managing one small kitchen counter.
Objective: Serve 8 correct orders before the shift ends.
Main obstacle: Orders expire if ignored too long.
Win condition: 8 correct orders are served.
Lose condition: 3 missed orders or the shift timer expires before 8 serves.

## Scope

Build the smallest complete Godot 4 2D project that teaches timed orders, UI button interaction, recipe matching, countdown state, scoring, mistakes, win/loss state, and restarting.

Do not add drag-and-drop, multiple stations, cooking animations, money, upgrades, customers with movement, multiple screens, save data, art polish, sound, settings, or shared framework code.
