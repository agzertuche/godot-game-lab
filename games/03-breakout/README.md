# Breakout

Player: A paddle moved left and right along the bottom of one screen.
Objective: Clear every block by bouncing the ball into them.
Main obstacle: Keeping the ball above the bottom edge.
Win condition: Every block is destroyed.
Lose condition: The ball leaves the bottom of the screen.

## Scope

Build the smallest complete Godot 4 2D project that teaches physics-style movement, collision response, reusable scenes, groups, simple level layouts, and restarting.

Do not add power-ups, multiple balls, multiple levels, scoring beyond the block count, art polish, sound, menus beyond what the loop needs, settings, or shared framework code.
