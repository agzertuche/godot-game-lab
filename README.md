# godot-game-lab
Small progressive 2D game projects for learning Godot and game development.

## Structure

- `games/01-dodge-blocks/` - Game 1: Dodge the Blocks.
- `games/02-collect-everything/` - Game 2: Collect Everything.
- `games/03-breakout/` - Game 3: Breakout.
- `shared/` - intentionally empty until at least two finished games prove that code or assets should be reused.

Each game should stay independently runnable as its own Godot project once implementation begins.
